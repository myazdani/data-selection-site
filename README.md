# Model-based data selection for LLM training

A dependency-free static webpage adaptation of the supplied Google Docs one-pager. The results figure is the paper figure in `eval_loss_books_hard_source.png`, and the linked paper is included locally as `colm2026-paper.pdf`.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

The site can be hosted directly with GitHub Pages: place this folder at the repository root, or configure GitHub Pages to publish from this folder if the repository layout allows it.
